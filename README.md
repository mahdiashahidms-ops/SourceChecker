# SourceChecker

A Chrome extension that extracts visible links and analyzes domain info, aiming to evolve into a tool that helps users examine webpage sources, redirects, and security signals  

---

## Current Features

* **Page & Domain Analysis**: Collects the current page’s title, URL, protocol, HTTPS status, and domain info. Subdomain and root domain parsing are still in development.
* **Smart Link Extraction**: Collects HTTP/HTTPS links from visible anchor elements, filtering out hidden or zero-size elements and duplicate links.
* **Popup Report**: Displays a summary of the current webpage alongside extracted links in a readable JSON format.
